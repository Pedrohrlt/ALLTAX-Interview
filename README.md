🧠 Sobre o projeto

O painel foi desenvolvido como parte do desafio técnico da ALLTAX, com foco em:

Organização de componentes React

Manipulação de estado e renderização condicional

Exibição de dados gráficos com clareza e usabilidade


💡 O que o projeto faz

Apresenta menus encadeados (categoria → produto → marca)

Atualiza o gráfico automaticamente conforme as seleções

Mostra o volume de vendas mês a mês

Interface responsiva, adaptada para desktop e mobile

🚀 Como rodar o projeto

Clone o repositório:

git clone https://github.com/Pedrohrlt/ALLTAX-Interview.git


Entre na pasta do projeto:

cd ALLTAX-Interview


Instale as dependências:

npm install


Inicie o servidor de desenvolvimento:

npm start


Acesse o app:

http://localhost:3000


🛠️ Tecnologias e Ferramentas

React – estrutura principal da aplicação

Vite – ambiente leve e rápido de build

Chart – biblioteca para visualização de dados

CSS – estilização e layout da interface
